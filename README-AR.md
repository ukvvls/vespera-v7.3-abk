# VESPERA Android — V7.2

تم إنشاء مشروع Android Studio مبدئي لتغليف نسخة VESPERA V7.2 كتطبيق Android عادي باستخدام WebView.

## ما يفعله المشروع
- يفتح موقع VESPERA الرسمي: https://ukvvls.github.io/vespera-V7.2/
- يفعّل JavaScript وDOM Storage حتى يعمل التطبيق والتخزين المحلي.
- يحتفظ WebView ببياناته بين مرات التشغيل على نفس تثبيت التطبيق.
- روابط المواقع الخارجية تفتح خارج التطبيق.
- زر الرجوع يتنقل داخل صفحات الموقع أولًا.

## مهم بخصوص البيانات
بيانات Chrome وبيانات WebView منفصلتان في Android. لذلك لا تنتقل بيانات VESPERA الموجودة في Chrome تلقائيًا إلى التطبيق. قبل أول استخدام للتطبيق، صدّر نسخة احتياطية من VESPERA في المتصفح، ثم افتح التطبيق واستورد النسخة من الإعدادات. لا تحذف بيانات المتصفح قبل التأكد من نجاح الاستيراد.

## بناء APK
1. افتح مجلد المشروع في Android Studio حديث.
2. اترك Gradle يعمل Sync، وتأكد من تثبيت Android SDK 35.
3. من Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
4. ملف APK يظهر عادة داخل `app/build/outputs/apk/debug/`.

## ملاحظات النسخة الأولية
- الأيقونة الحالية مؤقتة، وسيتم استبدالها بعد استلام مواصفاتك.
- التطبيق يحتاج اتصال إنترنت لتحميل الموقع من GitHub Pages. لم نضف وضعًا مستقلًا Offline للموقع بعد.
- لم نفعّل إشعارات Android الأصلية بعد؛ مركز الإشعارات داخل VESPERA يظل جزءًا من الموقع.
- هذا مجلد مشروع مصدر، وليس APK جاهزًا. بيئة البناء هنا لا تحتوي Android SDK أو Gradle، لذلك لم يمكن إخراج APK قابل للتثبيت مباشرة.

## بناء APK عبر GitHub Actions (بدون Android Studio على الهاتف)
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد أو إلى فرع جديد في مستودعك.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build VESPERA APK** ثم **Run workflow**.
4. بعد نجاح البناء افتح نتيجة التشغيل ونزّل Artifact باسم `VESPERA-V7.2-debug-apk`، ثم فك ضغطه لتحصل على APK.
